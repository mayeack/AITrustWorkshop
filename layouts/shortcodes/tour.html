{{- /* "Take the interactive tour" button that opens the workshop's published Navattic click-through, either at the start of the whole demo or deep-linked to one lab's flow. {{< tour >}} the whole demo (the Introduction) {{< tour "lab-1" >}} the first flow of Lab 1 (first line of each lab page) {{< tour "lab-1.2" >}} the Lab 1.2 flow (right under each `### Lab 1.2 …` heading) The demo is the one for the page's own section directory (ai-trust, ai-trust-open-weights).
