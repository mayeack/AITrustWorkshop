## What You Did

- **Lab 1 — Measure.** In PseudoCo Assistant you saw how aberrant behavior is identified, observed, and evaluated. In Splunk Agent Observability you saw every interaction scored automatically, surfaced unanticipated risks with Signals, tracked token usage and cost, saw how a custom evaluator for your industry is authored, and observed it flag a response outside the assistant's authority.
- **Lab 2 — Secure.** In PseudoCo Assistant you sent a prompt injection as a structured JSON request and saw the response carry the sensitive data it asked for. You then turned on Agent Security policy review, proved against the live application that the attack is blocked before it reaches the model, and traced the Prompt Injection block event in Agent Security.

## Outcome

**The gap.** Open-weight models give you control over which model runs, where it runs, and how it is governed — but control is not trust. A model you chose and host can still hallucinate, leak PII or other regulated data, absorb a prompt injection, or overstep its mandate, on any interaction, at machine speed.

**The value.** Trust becomes a loop you can run and prove. NVIDIA Nemotron open models, served as NVIDIA NIM microservices on Cisco Secure AI Factory with NVIDIA, provide the **intelligence**. Splunk Agent Observability provides the **evidence**. Agent Security provides the **enforcement**. In this workshop, Lab 1 measured an agent stepping outside its authority, and Lab 2 stopped a data-exfiltration attack before it reached the model — **evidence and enforcement, working together.**
